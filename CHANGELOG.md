## [0.1.0](https://github.com/DennisPohlmann/gameWE-web/compare/v0.0.0...v0.1.0) (2026-10-23)

### Features

* first public release v0.1.0 ([8cc4d55](https://github.com/DennisPohlmann/gameWE-web/commit/8cc4d55773cf9f385c034f6269d7838f9eb08501))

First public release: a new web frontend for the database of the gameWE
collector (HLstatsX/gameME schema), written from scratch as a replacement
for the HLstatsX:CE web. Next.js 16 (App Router, server-rendered, almost no
client JavaScript), React 19, TypeScript 7; MariaDB/MySQL via `mysql2` or
PostgreSQL via `pg`. Needs the gameWE collector 0.1.0 or newer and a
database created with its init script.

### Added

- **Games:** Counter-Strike: Source, Counter-Strike: Global Offensive,
  Counter-Strike 1.6, Day of Defeat (and Source), Team Fortress 2, Team
  Fortress Classic, Half-Life 2 Deathmatch, Half-Life Deathmatch and Natural
  Selection; Left 4 Dead, Left 4 Dead 2 and Insurgency as limited. Weapons,
  actions, teams, roles and awards come from the collector's definitions.
  Each ranking shows its game as a tag.
- **Start page:** all rankings with players online, best player (Steam
  picture, flag) and best clan, the load of the last 30 days per hour and a
  summary of kills, deaths and headshots.
- **Ranking page:** server list with one graph of all servers, each server
  with live players by team, its load graph and an "online now" map; daily
  awards; the latest 10 events (kills and actions) live, on page load or
  off; graphs per 15 minutes and per hour over 14 days with running totals
  of kills and headshots.
- **Server pages:** live view with bots and flags, load of the last 24 hours
  (players, maps, uptime), counters, chat.
- **Player ranking:** sortable, searchable, new players, country and city
  rankings (gameME's `?type=countryinfo|cityinfo` links work), a world map
  of the players (Leaflet), full pager (go to page, 25 to 250 rows).
- **Player profile:** Steam avatar and data, summary with radar and trend
  pills, player trend, rank with progress, career, ribbons, interactive
  hitbox, weapons table as on gameME (shots, hits, damage, accuracy, HPK
  ...), maps, teams, actions, player kill statistics, opponents, names,
  awards; history pages for events, sessions, awards and chat.
- **Awards:** daily awards with a calendar and history, ranks with insignia,
  ribbons with classes and most decorated players.
- **Weapons, actions, maps, teams/roles, clans, chat** pages; per map a kill
  heatmap (where players died or killers stood; Source games).
- **Misc page:** player countries, weekdays, connects per day, connect
  methods, server banners.
- **Bans page:** players banned in the server logs, bans from SourceBans
  (public ban list, also SB++) and, with `STEAM_API_KEY`, VAC and game bans
  from Steam.
- **Search** for players (name, earlier names, Steam ID in any form) and
  clans, in one or all rankings; **help page** with the points formula
  using the current settings, actions, weapon modifiers and chat commands;
  **licenses page**.
- **Images:** forum signature `/sig/<id>.png` and server banner
  `/banner/<id>.png`, classic or in the colours of any design template,
  with code as BBCode, HTML, Markdown or URL.
- **Sharing and SEO:** share bar on player, clan and server pages (plain
  links, no third-party scripts), Open Graph/X previews, `robots.txt`,
  `sitemap.xml`, configurable title format ("Page | Site").
- **Voice server box:** TeamSpeak 3 (via ServerQuery) or Discord (widget)
  with players online.
- **Public read-only JSON API** under `/api/v1` (rankings, servers, players),
  120 requests a minute per IP.
- **13 languages** (en, de, ru, es, fr, pt, pt-br, nl, da, pl, sr, zh-tw,
  zh-cn), browser language by default, English fallback.
- **Designs as templates** (CSS variables in `templates/`): orange, light,
  dark (default), blue, green, red and game designs for CS 1.6, CS:S,
  CS:GO, HL2DM, TF2 and DoD:S; own templates via `TEMPLATES_DIR`. Own logo,
  favicon and phone icon by path or URL.
- **Admin area** (`/admin`): settings for the website and the collector's
  `gamewe_*` options, rankings created from a template ranking, servers,
  players, clans, weapons, actions, teams, roles, awards, ranks (with
  insignia), users, chat and connect IP addresses (admins only), all
  `hlstats_Options` with explanations. Admins also see IPs and chat on
  player pages.
- **Reset ranking** (level 100): places a job that the running collector
  carries out (statistics only or everything); the page follows the job.
- **Admin sign-in** in two steps with optional TOTP (QR code), own password
  and TOTP under "My account", `create-admin` script.
- **Operations:** Docker image `ghcr.io/dennispohlmann/gamewe-web` and a
  tar.gz with a hardened systemd unit (`/opt/gamewe/web`, settings in
  `/etc/gamewe/web/web.env`); `BASE_PATH` set at start, so one build runs
  under any sub path; `TZ` for all times; access log on stdout; health
  endpoints `/healthz`, `/-/health`, `/-/liveness`, `/-/readiness` and
  Prometheus metrics at `/-/metrics` (token required).
- **CI:** every commit on `main` is built and checked and published as the
  image tag `edge`; semantic-release makes releases from Conventional Commits
  (tag, GitHub release with tar.gz and `.sha256`, image tags `<version>`,
  `<major>.<minor>` and `latest`).

### Changed (compared with the HLstatsX:CE web)

- Node.js/Next.js server instead of PHP; runs as a container or systemd
  service behind a reverse proxy.
- Look and structure follow gameME: breadcrumbs, sections bar, label/value
  tables, one table alignment (text left, numbers right, bars centred).
- PostgreSQL is supported next to MariaDB/MySQL with the same pages.
- A ranking is a row of `hlstats_Games` created in the admin area; servers
  are assigned there, and a server can only join a ranking of its game.
- Some values are computed by the website instead of read from tables the
  collector does not fill (today's award leaders, activity, maps and teams
  in the profile, best players per map).
- Maps use Leaflet with OpenStreetMap, OSM Humanitarian, OpenTopoMap or
  CARTO tiles (selectable, can be turned off) instead of Google Maps; only
  the GeoIP city point is used.
- Country and language flags are local SVGs (flag-icons) instead of images
  from external hosts; the signature embeds no remote pictures.
- Chat and player IPs are stored by default, but chat is public only when
  the setting allows it.
- Players can hide themselves from the ranking in the game
  (`!hideranking`); hidden profiles are not indexed.
- Award winners, leaders and rank counts are cached briefly, so the awards
  pages do not scan the event tables on every request.

### Security

- Two database users: the public pages use a SELECT-only user without
  access to `hlstats_Users`, RCON, chat and IP columns; admin writes use a
  separate admin user.
- All SQL through one module with placeholders; identifiers only from
  allowlists.
- Every admin page and server action checks the admin level itself.
- Session cookie signed with `ADMIN_SECRET`, `HttpOnly`, `SameSite=Strict`,
  `Secure` behind HTTPS, scoped to the base path; optional TOTP whose
  secrets are encrypted and hidden from the options list.
- Passwords stored as scrypt hashes; old HLstatsX MD5 hashes are upgraded
  on the next sign-in. Brake against guessing (10 failures, 15 minutes per
  IP) using the client address added by the reverse proxy.
- RCON passwords are write-only in the admin area and never read by public
  pages.
- Public pages, the API, feeds and images never show hidden players, IP
  addresses, RCON data, admin users or (unless allowed) chat; hidden
  rankings answer 404 to visitors.
- SourceBans is read only from public http(s) addresses without redirects
  (`SOURCEBANS_ALLOW_PRIVATE=1` for the LAN); `/-/metrics` needs a bearer
  token of at least 16 characters.

### Removed (compared with the HLstatsX:CE web)

- The PHP code base, its installer and its database update scripts; the
  database is created only by the collector's init script.
- Reset and database tools of the web admin that changed statistics
  directly; a reset now goes through the collector.
- The real name, e-mail and homepage profile fields and their in-game
  commands; the unused server field "Status URL".
- Google Maps and remote flag images.

### Known limitations

- Left 4 Dead, Left 4 Dead 2 and Insurgency are limited: the collector
  records kills, connects and teams, but has no template definitions for
  them yet.
- Kill heatmaps need positions in the logs, which only Source games write.
- Counter-Strike 2 is not supported.
- The admin area is in German and English only.
